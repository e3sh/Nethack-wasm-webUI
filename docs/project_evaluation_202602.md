# プロジェクト開発状況レポート (2026年2月)

## 1. プロジェクトの目的
本プロジェクト「NetHack-wasm-webUI」は、NetHack 3.7.0のブラウザ実行環境において、操作性の向上と日本語環境の提供を目的とした開発を行っています。Canvasベースの描画エンジンおよび動的な翻訳システムの実装により、クロスプラットフォームでのプレイ環境構築を目指しています。

## 2. 開発進捗
現在の主要機能の実装状況は以下の通りです。

### A. コアエンジン & 描画システム
- **NetHack-WASM 統合**: Asyncifyを用いた統合により、ブラウザ上での安定的な動作を確認済み。
- **描画処理**: Canvasを用いた独自実装により、ASCII、日本語フォント、およびタイルの混在表示に対応。
- **パフォーマンス**: 描画ロジックの最適化により、一通りのレスポンス性能を確保。

### B. 入力システム
- **コンテキスト対応システム**: 
    - メニュー、YN選択、方向入力などの状態に応じたボタンマッピングの動的な切り替え機能を実装。
    - ゲームパッド使用時の操作性を考慮した設計。
- **タッチ操作**: 
    - モバイル端末向けのバーチャルパッドおよびコンテキスト依存のボタン配置を実装。
- **入力の抽象化**: キーボード、ゲームパッド、タッチ入力を統一的に扱う抽象化レイヤーを構築。

### C. UI/UX
- **設定画面**: 各種オプションを設定可能なGUIコンポーネントを実装。
- **設定の永続化**: ユーザー設定を `localStorage` 等に保存・復元する機能を搭載。

### D. 翻訳・国際化
- **動的パース**: アイテム名やメッセージを分解し、日本語として再構成するエンジンのプロトタイプを運用中。
- **辞書管理**: 翻訳データの効率的な編集・適用のための基盤を整備。

## 3. 他のNetHack Web実装との主な相違点

| 項目 | 一般的なWebポート | **本プロジェクト (Nethack-wasm-webUI)** |
| :--- | :--- | :--- |
| **ベースバージョン** | 3.4.3 / 3.6.x | **3.7.0 (開発版)** |
| **日本語対応** | 英語が標準 | **動的パースによる日本語翻訳を統合** |
| **描画方式** | ターミナルエミュレート | **Canvasによるフォント・タイルの混在表示** |
| **入力UI** | 主にキーボード | **パッド/タッチへのコンテキスト依存マッピング** |
| **外部ハードウェア** | モバイルではキーボード推奨 | **タッチ操作による単体プレイに対応** |

## 4. 現在の課題と今後の注力領域

### 📱 モバイル環境のレイアウト最適化
- 端末の画面比率（アスペクト比）によってはUI要素の重なりや見切れが発生するため、レスポンシブな配置調整が必要です。

### ⚙️ 操作感の微調整
- 実装された各入力方式（パッド、タッチ）のデフォルトレイアウトについて、実際のプレイを通じたフィードバックに基づき、より自然な配置を模索する段階にあります。

### 🌍 辞書データの拡充
- 翻訳精度の向上のため、未翻訳メッセージの抽出と辞書への反映を継続的に行う必要があります。

## 5. まとめ
本プロジェクトは基盤となる主要機能の実装を概ね完了し、現在は実際のプレイにおける利便性を向上させるための微調整フェーズに入っています。今後はモバイル端末での操作性改善を中心に、プロダクトとしての安定性と完成度を高めていく予定です。
