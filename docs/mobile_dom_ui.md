# モバイル向け DOM UI システム仕様書

## 1. 概要
本プロジェクトのモバイル版 (`mobile.html`) では、従来の Canvas ベースの描画エンジンに代わり、HTML 要素を直接操作する **DOM レンダラー** を採用しています。これにより、モバイル端末での消費電力低減、文字の鮮明化、およびタイル表示の高速化を実現しています。また、画面サイズに応じた柔軟なレイアウト調整（レスポンシブ対応）を搭載しています。

## 2. 構成コンポーネント

### 2.1 DisplayManager.js
レンダリング環境を判断し、適切な描画デバイスを生成・管理する中央管理クラスです。
- **抽象化**: 実行環境がモバイル（`#ui-root` の存在）かデスクトップかを判定し、`mobileCurses` または `jncurses` を透過的に生成します。
- **コンソール管理**: 名前ベース（"MAP", "STATUS" 等）で各描画領域を管理し、レイアウト情報の保持と表示制御を行います。

### 2.2 LayoutManager.js
画面解像度や向きに応じた動的なレイアウト調整を担当します。
- **レスポンシブ制御**: ウィンドウサイズ（`width`, `height`）に基づき、各コンソールの位置 (`x`, `y`) とサイズ (`w`, `h`) を動的に書き換えます。
- **小画面最適化**: 低解像度端末では、ステータス表示の簡略化 (`setSimpleSL`) や縦スクロールの有効化 (`setVScroll`) を自動的に行い、プレイアビリティを確保します。

### 2.3 mobileCurses.js
`jncurses.js` をモバイル向けに再実装したクラスです。
- **軽量化**: Canvas のピクセル操作を廃止し、行ベースの DOM 更新（`div.jn-line`）を採用。
- **ハイブリッド描画**: 通常テキストはブラウザの等幅フォント、タイル画像は CSS Sprite + `span` 要素で描画します。

### 2.4 barEffect.js (DOM版)
HP/MP の残量を視覚的に表示する機能です。
- **ネイティブ要素の活用**: HTML5 の `<meter>` 要素を利用し、アクセシビリティと描画効率を両立。
- **エフェクト**: ダメージ時の追従エフェクト（赤いバー）も DOM 要素のサイズ調整で実現しています。

## 3. 主要機能の仕組み

### 3.1 日本語・マルチバイト文字の表示
DOM 版では OS 標準の等幅フォントを使用するため、ピンチズーム等の拡大操作に対しても文字が鮮明に保たれます。

### 3.2 タイル（グリフ）表示
文字列中の `0x100` 以上のコードをタイルとして識別し、CSS の `background-position` で切り出した画像をインラインで挿入します。

### 3.3 自動セーブ連携遷移
モバイル版 (`mobile.html`) からデスクトップ版 (`index.html`) へ切り替える際、`Shift+S` コマンドの自動送出と IndexedDB の同期待機を行い、安全に状態を引き継ぎます。

## 4. 小画面・レスポンシブ対応（解消済み）

開発当初課題となっていた小画面でのレイアウト崩れは、以下の実装により解消されています。

- **可変レイアウト**: `LayoutManager` により、端末の解像度に合わせて「マップ」「メッセージ」「ステータス」の各領域が最適化された位置に再配置されます。
- **ステータス表示の簡略化 (SIMPLEモード)**: 画面幅が不足する場合、重要度の高い情報（HP, Pw, Exp）に絞った表示に自動的に切り替わります。
- **縦スクロールの導入**: 画面の高さが不足する場合、UI全体に縦スクロールを導入し、隠れた情報へアクセス可能にしています。

## 5. 今後の展望
- **ユーザーカスタマイズ**: レイアウト微調整のユーザー設定保存機能。
- **テーマ対応**: CSS 変数を用いた、より詳細な配色・外観のカスタマイズ。
