# NetHack-wasm-webUI 開発状況まとめ & 引き継ぎ資料 (2026年8月29日)

本文書は、2026年8月17日（`WebUICore` サブモジュール構造化、Game Knowledge Layer (GKL) 基礎導入、全領域 Glyph 統一検索完了）から本日（2026年8月29日）までの開発実績、アーキテクチャの階層化・SSOT化、戦術助言・行動アシスト基盤の構築、演出トリガー基盤、単体テストスイートの大幅拡充（67件 ➔ 338件 100% PASS）、および次回以降のセッションへ向けた引き継ぎ事項を包括的にまとめたレポートです。

---

## 1. 概要 (Overview)

前回の GKL 基礎基盤の構築以降、本期間（2026/08/17 〜 2026/08/29）では、NetHack 特有の難解なルールや JRPG メンタルモデルとの乖離を解消し、プレイヤーが迷わず安全に行動できる **「戦術助言・行動指針（Action Stance）アシスト基盤」** および **「演出トリガー＆SSOT（Single Source of Truth）データ駆動型アーキテクチャ」** への飛躍的進化を達成いたしました。

主たる達成事項は以下の通りです：

1. **WASM通信ドライバー層 (`NetHackWasmDriver.js`) の同期・キューイング基盤の確立**:
   - `lastSequenceBuffer` アーキテクチャにより、Cコア内部メモリの泥臭いハック（ポインタ直接参照等）を 0% に抑え、シーケンス実行中の出力バッファを 100% 安全かつ汎用的に捕捉・返却。
   - `queueSequence` の直列キューイング制御、`stepDelayMs` / `allowMapUpdates` オプション、`select_menu` のインデックス/アクセラレータ自動選択、サイレント問い合わせ API (`querySequenceSilent`) の統合。
2. **`WebUICore` のインフラ化と疎結合化 (SoC)**:
   - `WebUICore`（通信・UIインフラ基盤）と GKL（ドメイン知識・制御層）の責務を厳格に分離（ADR 1.5, 1.8, 1.9）。
   - 未識別スクロール・ポーション使用時の名付けプロンプト制御モード (`Auto-Skip`, `Auto-memo`, `Manual`) の新設、リスタート不具合解消、完全破棄 (`destroy()`) ライフサイクルの保証。
3. **戦術助言エンジン [`TacticalAdvisor.js`](file:///c:/Users/e3-sh/Documents/GitHub/Nethack-wasm-webUI/src/core/knowledge/TacticalAdvisor.js) の新設**:
   - 即時行動（1ターン消費）と戦術助言（ターン非消費の危険予知・最適化提案）の責務を完全分離。
   - コカトリス石化、浮遊目玉麻痺、ガス胞子爆発、溶岩・水没ハザード、銀特効、手品袋爆発ハザード、熟練武器適正、最適装備を純粋関数型モデルで自動評価。
4. **行動指針 (Action Stance) ＆ アシストシグナル基盤 ([`AssistSignalSynthesizer.js`](file:///c:/Users/e3-sh/Documents/GitHub/Nethack-wasm-webUI/src/core/knowledge/AssistSignalSynthesizer.js)) の新設**:
   - JRPGメンタルモデルとの乖離を解消し、特効薬がない状況での「安全な過ごし方（足踏み待機、祈り、Elbereth結界等）」を提示。
   - 3層情報圧縮モデル（Level 1: 極小バッジ/枠線、Level 2: HUD 1行最優先シグナル、Level 3: ワンタップ実行＆理由展開）により、ボタン乱立と情報過多を防止。
5. **GKL 4層パイプライン構造 & 動的状態マネージャー群の充実**:
   - [`SituationCache.js`](file:///c:/Users/e3-sh/Documents/GitHub/Nethack-wasm-webUI/src/core/knowledge/SituationCache.js) を中核に、[`MonsterTracker.js`](file:///c:/Users/e3-sh/Documents/GitHub/Nethack-wasm-webUI/src/core/knowledge/MonsterTracker.js) (視界外敵の追跡・減衰モデル), [`SkillStateManager.js`](file:///c:/Users/e3-sh/Documents/GitHub/Nethack-wasm-webUI/src/core/knowledge/SkillStateManager.js) (`#enhance`), [`SpellStateManager.js`](file:///c:/Users/e3-sh/Documents/GitHub/Nethack-wasm-webUI/src/core/knowledge/SpellStateManager.js) (`+`), [`AttributeStateManager.js`](file:///c:/Users/e3-sh/Documents/GitHub/Nethack-wasm-webUI/src/core/knowledge/AttributeStateManager.js) (`^X`), [`DiscoveryStateManager.js`](file:///c:/Users/e3-sh/Documents/GitHub/Nethack-wasm-webUI/src/core/knowledge/DiscoveryStateManager.js) (`\`), [`OnDemandLookService.js`](file:///c:/Users/e3-sh/Documents/GitHub/Nethack-wasm-webUI/src/core/knowledge/OnDemandLookService.js) (平和的NPC・石像・ペット検知) を統合。
   - 静的ナレッジの初回遅延固定化 (Lazy Memoization) と動的ステート合成 (ADR 1.10) により、起動遅延ゼロ・毎ターンの翻訳負荷ゼロ・不整合リスクゼロを両立。
   - AC変化検知による盗難・装備破壊のゼロオーバーヘッド即時同期 (ADR 1.13 / Phase 1) を実装。
6. **演出トリガーイベント基盤 ([`GKL_Visual_FX_Event_Architecture.md`](file:///c:/Users/e3-sh/Documents/GitHub/Nethack-wasm-webUI/docs/3_gkl/GKL_Visual_FX_Event_Architecture.md))**:
   - `fx_trigger` イベント (`ATTACK_HIT`, `DAMAGE_TAKEN`, `KILL_CONFIRMED`, `RECOVER_HEAL`, `PLAYER_DIED`, `PLAYER_RESURRECTED`) を導入。
   - 死亡時の墓石描画・蘇生復元、斬撃エフェクト、被弾画面微小シェイクを、ターン操作のテンポを一切ブロッキングせずに実現。
7. **GKL Pure JS クライアント ([`examples/gkl-pure-js-client/`](file:///c:/Users/e3-sh/Documents/GitHub/Nethack-wasm-webUI/examples/gkl-pure-js-client)) の刷新**:
   - FocusCamera の表示領域を 7×7 から 21×9 へ大幅拡大。
   - コンポーネント別 (`modules/components/`, `modules/handlers/`, `modules/renderers/`) に完全ファイル分割・リファクタリング。
   - 階段キャッシュによる再訪フロアの階段即時描画、ボルダー移動表示、所持品長押しサブメニュー、ワンタップ魔法詠唱 (`z`)、多言語切替の完全追従を実装。
8. **単体テスト自動化の爆発的拡充 (Vitest & node:test)**:
   - 単体テスト数が **67 件から 338 件へと約 5 倍に激増**。全 32 テストスイートが 100% PASS を達成。
   - 全 9,623 個の Glyph 検証テスト (`AllGlyphsVerification.test.js`) およびドライバー層テスト (`NetHackWasmDriver.test.js` 12件) も継続 100% PASS。

## 2. 2026/08/17 〜 2026/08/29 の主な開発・更新実績

### 🔌 A. WASM通信ドライバー層のキューイング制御とサイレントクエリ基盤 (2026/08/18〜08/20, 08/23)
- **`lastSequenceBuffer` アーキテクチャの確立 ([`NetHackWasmDriver.js`](file:///c:/Users/e3-sh/Documents/GitHub/Nethack-wasm-webUI/src/driver/NetHackWasmDriver.js), ADR 1.2, 2.1)**:
  - C言語内部のメモリポインタ（`struct obj *invent` 等）を無理に解析することなく、シーケンス実行中に Cコアが発行するテキスト・メニュー構造体をドライバー内部のバッファへ自動収集。
  - シーケンス完了時に結果バッファを Promise の戻り値として直接返却するクリーンなインターフェースを実現。
- **連続シーケンス実行制御と FIFO タスクキュー**:
  - `queueSequence` における連続呼び出し時の競合・混信を排除する FIFO キュー機構を実装。
  - `stepDelayMs`（ステップ間遅延時間）および `allowMapUpdates`（シーケンス中のマップ描画許可）オプションを追加し、アニメーションや複数ステップキーの確実な実行を保証。
  - `select_menu` での letter/index 指定による確実な選択応答を実装。
- **サイレントクエリ (`querySequenceSilent`)**:
  - 画面描画やメッセージ通知を非表示にしたまま、インベントリ (`i`) や呪文 (`+`)、スキル (`#enhance`) 等を裏で高速実行して結果を取得する統一パイプラインを確立。

### ⚙️ B. WebUICore のインフラ化・安定化・DevTools 統合 (2026/08/18, 08/20〜08/26)
- **`WebUICore` と GKL の責務分離 (ADR 1.5, 1.8)**:
  - `WebUICore` はゲーム固有ルールを持たない純粋な通信・描画・UIインフラ基盤に専念し、GKL を独立プラグインモジュールとして疎結合化。
  - `WebUICore.destroy()` の重複防止と完全なリソース破棄処理を実装。
  - Canvas 描画のイベント駆動化により、常時ポーリングによる CPU 負荷を大幅削減。
- **名付けプロンプト (`Auto-Skip`, `Auto-memo`, `Manual`) 制御モード**:
  - 未識別の巻物やポーションを使用した際、NetHack が要求するアイテム名付けプロンプトに対し、設定（config）に応じて自動スキップ・自動直前メッセージ入力・手動入力を選択可能に改修。
- **プロンプト表示不具合・リスタート不具合の解消**:
  - 質問プロンプト (`ynq`) が行入力として誤認識される問題や、リスタート (`restart()`) 時に前回の状態が残る問題を完全修正。
- **DevTools インスペクター ([`DebugInspector.js`](file:///c:/Users/e3-sh/Documents/GitHub/Nethack-wasm-webUI/src/core/inspector/DebugInspector.js)) の進化**:
  - 未翻訳メッセージ自動収集機能を DevTools インスペクターへ統合。既知翻訳エントリをフィルタリングし、真の未翻訳テキストのみを正確に抽出・記録。

### 🛡️ C. TacticalAdvisor (戦術アドバイザー) の新設 (2026/08/23〜08/25)
- **即時行動と戦術助言の完全分離 ([`TacticalAdvisor.js`](file:///c:/Users/e3-sh/Documents/GitHub/Nethack-wasm-webUI/src/core/knowledge/TacticalAdvisor.js), [`TacticalAdvisor_Specification_and_Architecture.md`](file:///c:/Users/e3-sh/Documents/GitHub/Nethack-wasm-webUI/docs/3_gkl/TacticalAdvisor_Specification_and_Architecture.md))**:
  - `ContextActionEngine` から警告・助言ロジックを切り離し、ターンを消費しない純粋関数型エンジンとして新設。
- **4大トピックによる多角的危険予知**:
  1. **THREAT (即死・致命的脅威・環境ハザード)**:
     - コカトリス（手袋未着用での近接攻撃による石化警告）
     - 浮遊する目玉（目隠しなしでの近接攻撃による麻痺警告）
     - ガス胞子（近接攻撃時の大爆発警告）
     - 溶岩マス（進入即死・アイテム全焼失警告）
     - 水場マス（所持品水没破損・防具錆び警告）
     - 露出した罠（落とし穴・熊罠等）
     - 手品袋の爆発ハザード（軽量化袋への誤投入による消滅爆発警告）
  2. **EQUIPMENT (熟練武器適正 ＆ 最適装備)**:
     - スキルランク（達人・熟練・入門・未熟）と武器ダイス・強化値・BUCを総合評価し、より適した武器への持替を助言。
  3. **RESISTANCE & INTRINSICS (耐性 ＆ 固有能力)**:
     - ドラゴンやビーム敵に対し、所持している耐性装備（火炎・冷気・電撃・反射等）の未着用を検知して警告。
  4. **TACTICS & COMBAT (戦術・戦闘支援)**:
     - 悪魔・アンデッドに対する銀武器特効の提案。
     - Elbereth結界の刻印推奨 (`ACTION_ENGRAVE_ELBERETH`)。
     - 店主・平和的NPC（Peaceful）の誤爆防止・脅威度適正判定。

### 🚨 D. 行動指針 (Action Stance) ＆ アシストシグナル基盤 (2026/08/25〜08/27)
- **JRPGメンタルモデルの乖離解消 ([`AssistSignalSynthesizer.js`](file:///c:/Users/e3-sh/Documents/GitHub/Nethack-wasm-webUI/src/core/knowledge/AssistSignalSynthesizer.js), [`Assist_Signal_and_Stance_Architecture.md`](file:///c:/Users/e3-sh/Documents/GitHub/Nethack-wasm-webUI/docs/3_gkl/Assist_Signal_and_Stance_Architecture.md))**:
  - 特効薬が存在しない NetHack の定石（状態異常が治るまで足踏み待機、壁際退避、神への祈り `#pray`）を自動評価し、最も安全な行動指針（Stance）をサジェスト。
- **3層情報圧縮モデル (3-Tier Information Model)**:
  - **Level 1 (Nano Badge / 極小バッジ・枠線)**:
    - 所持品スロットや魔法スロットに `[💊緊急回復]`, `[🔥治療]`, `[⚠️高失敗(XX%)]`, `[🎯特効]` などの極小バッジや金枠・赤枠パルスを分散付与。
  - **Level 2 (1-Line Signal / HUD最上部バー)**:
    - 優先度スコアリング（90+即死 ➔ 80+生命 ➔ 60+状態 ➔ 40+装備 ➔ 20+利便）により、画面最上部に現在最も生存確率を高める1行（10〜20文字）を厳選表示。
  - **Level 3 (Action & Why / ワンタップ即時実行 ＆ 理由アコーディオン)**:
    - ワンタップで安全なキーストローク（足踏み待機 `.`、祈り `#pray`、杖発動 `z` 等）を実行し、クリックで長文理由とWiki解説を展開。
