💡 開運用ヒント

静的ローカルサーバー（例: python -m http.server 8000 や Live Server）を起動した状態で http://localhost:8000/tools/cltest.html へアクセスすることで全クライアントを一元テスト・管理できます。
各フレームワークの開発サーバーを起動する場合は npm run dev:vue などをプロジェクトルートで実行してください。
