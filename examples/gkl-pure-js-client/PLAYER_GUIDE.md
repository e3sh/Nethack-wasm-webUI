# 【Nehww】操作ガイド

公式リファレンスクライアント **Nehww** の操作ガイドです。マウスまたはキーボード（左手 WASD / テンキー）を使用して快適にプレイできます。

---

## 1. 入力モード切替 (`F1` キー)

Nehww では、プレイヤーの好みに合わせて2つの入力モードを `F1` キー（またはヘッダーのボタン）でいつでも即座に切り替えられます。

- **🛡️ Nehww モダンモード（標準）**:
  - 左手 **WASD 移動 ＋ マウス操作 ＋ 決定（`Space`）** による直感的でテンポの良いモダン操作系。
  - ターン消費ゼロの「その場向き変更」や、通路を自動で曲がる「ダッシュ」、文脈に応じた「スマートメニュー」を活用できます。
- **⚔️ Classic 原作モード**:
  - テンキー（`1`〜`9`）や矢印キー、および NetHack 伝統の全コマンドキーが 100% Cコアへ直接送信される原作互換操作。

---

## 2. Nehww モダン基本操作

NetHack 固有の複雑なキーコマンドを暗記していなくても、**左手キーボード ＋ 右手マウス** だけで快適に冒険を進められます。

### 🕹️ 移動・向き転換・ダッシュ
| 操作 | キー / マウス | 動作内容 |
| :--- | :--- | :--- |
| **8方向通常移動** | `WASD` / `QWEADZXC`<br>または 矢印 / テンキー | 1マス歩行。`W`:北, `S`:南, `A`:西, `D`:東（`X` も南）。<br>※移動先のマスを左クリックすることでも移動可能。 |
| **その場向き転換** | `Shift + WASD`<br>（または `Shift + 方向`） | **ターンを消費せずにその場で向き（Facing）を変更**。<br>足元の水色矢印（▲）と目の前のフォーカス枠が回転します。 |
| **通路駆け抜けダッシュ** | `Ctrl + WASD`<br>（または `Ctrl + 方向`） | **その方向へ一気に走る（奔走ダッシュ）**。<br>通路の曲がり角を自動で曲がりながら、角や扉、部屋に出るまで駆け抜けます。 |
| **その場待機** | `.` (ピリオド) または テンキー `5` | その場で1ターン待機・警戒します。 |

---

### ⚡ 決定 ＆ スマート文脈インタラクト
自キャラが向いている方向（Facing）や足元の状況を検知し、最適な行動を提示します。

- **`Space`（目の前インタラクト）**:
  - 向いている目の前に対象（扉、モンスター、罠、アイテムなど）がある場合、**アクションメニューがポップアップ**します。
  - メニュー展開中:
    - **数字キー `1`〜`9`**: 各ボタンに付与された番号 `[1]`, `[2]` で即座に実行
    - **`Space` または `Enter`**: 選択中のアクションを実行
    - **`W` / `S` または 上下矢印**: 選択カーソルの移動
    - **`Esc`**: メニューを閉じる
  - ※目の前に何もない場合は、足元アクションまたは周囲の単一扉を自動補完してインタラクトします。
- **`Shift + Space`（足元インタラクト）**:
  - 向きに関係なく、**自キャラ足元（アイテムを拾う、階段の昇降、祭壇で祈る、流し台、待機など）のメニューを強制展開**します。

## 3. マウス操作

マウスのみでもすべての操作・ゲーム進行が可能です。

- **左クリック**:
  - 空いている床: 最短経路で自動移動（Travel）。
  - 隣接する扉・モンスター・宝箱: コンテキストアクションメニューを展開。
  - 自キャラ足元: 足元メニュー（拾う、階段等）を展開。
  - 所持品アイコン: 自動判別で使用（食料は食べる、未装備品は装備）。
- **右クリック**:
  - 指定マスの詳細情報（Inspect）やサブメニューを表示。
- **マウスホイール**:
  - ホイール回転: ビューポートのズーム拡大・縮小。
  - ホイールクリック: ズーム倍率を等倍（1.0x）にリセット。

## 4. 画面の見方

- **自キャラ足元**: 水色の向き三角マーカー（▲）が向いている方向を示します。
- **目の前枠**: 向いている目の前のマスが点線枠でハイライトされます。
- **エンティティ強調**:
  - 自キャラ: 緑枠線
  - ペット: 緑リング（`[♥]`）
  - 騎乗モンスター: 水色リング（`[R]`）
  - 重なったアイテム: 黄色バッジ（`[+]`）
- **スマートガイドバー（画面下部）**:
  - 画面最下部に主要キー（`Space: 目の前`、`Shift+Space: 足元`、`Shift+WASD: 向き`、`Ctrl+WASD: ダッシュ` 等）のガイドを常時表示。
- **支援ダイアログ**:
  - 願い (`wish`)、虐殺 (`genocide`)、変身 (`polymorph`)、筆記 (`write`) 発生時に、安全なキーワード候補の選択や事故防止警告が自動表示されます。

---

## 5. 設定メニュー (⚙️)

画面右上の「⚙️ 設定」から各種表示の切り替えが可能です（ブラウザに自動保存されます）。

- **外観プリセット**:
  - `🛡️ GKLモダン (標準)`: HD-2D表示と各種支援HUDを有効化した標準レイアウト。
  - `⚔️ クラシック (原作風)`: ASCII表示、サイドパネル退避、2行テキストステータスによる原作再現レイアウト。
- **表示方式・カメラ**:
  - ビュー切替: HD-2D（立体視ジオラマ） / 2Dグラフィック / ASCII
  - カメラ切替: ジオラマ（見下ろし） / トップビュー（真上）
  - ミニマップ表示、デバッグHUDのON/OFF
- **システム操作**:
  - `Restart`: タイトル画面へ戻る。
  - `Delete Save`: 保存されているセーブデータを消去して初期化。

※通常プレイ中の `/`（What is this?）や `\`（Known objects）は NetHack 本来のコマンドとしてネイティブ透過されます。
