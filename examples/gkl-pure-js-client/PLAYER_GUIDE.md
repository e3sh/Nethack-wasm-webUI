# 【Nehww】操作ガイド

公式リファレンスクライアント **Nehww** の操作ガイドです。マウスまたはキーボードを使用して操作します。

---

## 1. 基本操作

NetHack固有のキーコマンドを把握していなくても、画面のクリックとボタン選択のみで進行可能です。

### 移動と主要アクション
- **移動**: 移動先のマスをクリック / 矢印キー / テンキー (1〜9)
- **決定・メッセージ送り**: `Space` または `Enter`（`--More--` 表示時も同様）
- **足元で待機 (1ターン経過)**: `.`（ピリオド）キー
- **キャンセル・ウィンドウを閉じる**: `Esc` または `q` キー
- **アイテムの使用・装備**: 所持品アイコンを左クリック（食料は食べる、未装備品は装備など状況に応じて自動判別）
- **対象に対する行動**: 対象マスをクリック、または右パネルの「おすすめ行動」ボタンを選択
- **視点（ズーム）**: マウスホイール回転で拡大・縮小、ホイールクリックで等倍リセット

※従来のNetHackキーコマンド（`e` で食べる、`q` で飲む、`#` で拡張コマンドなど）もそのまま入力可能です。

## 2. 画面構成

- **ダンジョンマップ（中央全画面）**:
  - 左クリックで最短経路移動、または隣接対象のアクションメニュー表示。
  - 右クリックでコンテキストメニューおよび詳細調査（Inspect）を表示。
  - 自キャラには緑枠線、ペットには緑リング（`[♥]`）、騎乗モンスターには水色リング（`[R]`）、重なったアイテムには黄色バッジ（`[+]`）が表示されます。
- **メッセージHUD / 過去ログ（上部・左側）**:
  - 画面上部に最新メッセージを表示。
  - メッセージクリック、または `Ctrl+P` で過去ログドロワーを展開（📌ボタンで左側に常時固定可能）。
- **ステータスバー（画面下部）**:
  - HP/MPゲージ、階層（Dlvl）、AC、所持金、能力値を表示。
  - `Dlvl` をクリック: フロア記録・メモ画面を開く。
  - `詳細` ボタンをクリック: キャラクター詳細ステータス画面を開く。
- **右サイドパネル（画面右側）**:
  - `Alt+S` または `F2` キー、あるいはヘッダーの「🎒 パネル ⏵」で一時退避・復帰が可能。
  - **所持品**: アイコン一覧。左クリックで使用、右クリック/長押しでサブメニュー（投げる、置く、仮名付け等）を表示。
  - **おすすめ行動**: 隣接する扉、モンスター、宝箱などに対して実行可能なアクションを表示。
  - **戦術アドバイス**: 空腹、毒、体力の低下、危険なモンスターへの対処法をリアルタイムに提示。
- **ヘッダーバー（最上部）**:
  - 各種機能画面（ステータス、装備、ログ、冒険手帳、設定）へのショートカットボタンを配置。

## 3. 主要機能とショートカット

| 機能 | キー / 操作 | 概要 |
| :--- | :--- | :--- |
| **フロア記録・メモ** | `Ctrl+O` / `Alt+A`<br>または `Dlvl` クリック | 全階層の踏破状況、階段・店・祭壇・泉等の設備一覧の確認、フロアメモ (`#annotate`) の記入、現在地への絵文字ピン・マーカー設置。 |
| **冒険手帳 (Codex)** | `\` または `¥`<br>またはヘッダー「📖」 | セッション横断の知識アーカイブ。モンスター・アイテム図鑑、噂話（真偽判定付き）、神託、床文字の記録閲覧と検索。 |
| **装備ペーパードール** | ヘッダー「🎽」<br>または所持品「装備詳細」 | 全身13スロットの装備一覧。AC変化の比較、着脱にかかるターン数の確認、呪い装備の警告。 |
| **キャラクター詳細** | ヘッダー「👤」<br>またはステータス「詳細」 | 能力値内訳、内在・外在耐性一覧、修得呪文の詠唱、スキル向上 (`#enhance`)。 |
| **コンテナ管理** | 箱・袋を開ける | 宝箱や鞄とのアイテム・金貨の相互移動。バッグ・イン・バッグ等の危険な収納は自動で防止。 |
| **ミニマップ展開** | `Tab` キー<br>またはミニマップクリック | 画面中央に全体マップを透過オーバーレイ表示。通常時は自キャラの位置に応じて自動退避・透過。 |
| **ナレッジ調査** | `/` キー<br>またはマス右クリック | 指定マスのモンスター、アイテム、地形ギミックの構造化詳細情報を表示。 |
| **支援ダイアログ** | （イベント発生時に自動起動） | 願い (`wish`)、虐殺 (`genocide`)、変身 (`polymorph`)、筆記 (`write`) 発生時に、安全なキーワード候補の選択や事故防止警告を表示。 |

## 4. 設定メニュー

画面右上の「⚙️ 設定」から各種表示・動作の切り替えが可能です（設定はブラウザに自動保存されます）。

- **外観プリセット**:
  - `🛡️ GKLモダン (標準)`: HD-2D表示と各種支援HUDを有効化した標準レイアウト。
  - `⚔️ クラシック (原作風)`: ASCII表示、サイドパネル退避、2行テキストステータスによる原作再現レイアウト。
- **表示方式・カメラ**:
  - ビュー切替: HD-2D（立体視） / 2Dグラフィック / ASCII
  - カメラ切替: ジオラマ（見下ろし） / トップビュー（真上）
  - ミニマップ表示、デバッグHUDのON/OFF
- **キー入力**:
  - `キー入力のネイティブ透過`: `/` や `\` キーの入力を、Nehwwの独自ダイアログではなくNetHack本来のコマンドとして直接送信する設定。
- **システム操作**:
  - `Restart`: タイトル画面へ戻る。
  - `Delete Save`: 保存されているセーブデータを消去して初期化。
