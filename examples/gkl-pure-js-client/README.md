# NetHack Wasm WebUI - GKL Pure JS Reference Client

`examples/gkl-pure-js-client` は、**Pure JS Client (`examples/pure-js-client`)** の安定した完全なクライアント基盤（全プロンプト、メニュー、キー入力、WASM Worker 通信、セーブ・復元等）をベースに、**GKL (Game Knowledge Layer)** のインテリジェント機能を完全統合したリファレンスクライアントです。

---

## 🌟 主な特徴と GKL 拡張機能

1. **完全な NetHack UI インフラ基盤**
   * 名前入力 (`ASKNAME`)、キャラクター作成ダイアログ (`CHOICE_BUTTONS`)、メニュー選択 (`MENU`)、情報表示 (`TEXT`) などのあらゆる入力プロンプトを 100% サポート。
   * セーブデータの自動検出、再開、削除、ゲームオーバー・ハイスコアボード表示をサポート。

2. **🧠 GKL 推奨アクションパネル (`ContextActions`)**
   * 足元の地形・仕掛け、周囲のモンスター、手持ちの道具（採掘工具・鍵・杖など）から「今最も有益なアクション」を優先度順にリアルタイム自動提示。
   * ボタンワンタップで行動を自動実行（危険な行動は警告ポップアップ保護）。

3. **🎯 自キャラ周辺 拡大ズームカメラ窓 (`Focus Camera Viewport`)**
   * マップ右上に自キャラを中心とする 7x7 マス（32px 大きめタイル）の「拡大カメラ窓」をオーバーレイ表示。
   * 自キャラの位置をネオングリーン枠で常に追従表示し、周囲の壁・扉・アイテム・近接敵の状況を大画面で鮮明に把握可能（ボタンで ON/OFF 切替可）。

4. **🎒 アイコン型所持品インベントリ ＆ 💡 ターゲット構造化ナレッジパネル**
   * 所持アイテムをグリッドアイコンで常時可視化。
   * マップタイルやインベントリのホバー/選択時に、対象モンスターの「危険度バッジ (LETHAL/HIGH/MEDIUM/LOW)」「ステータス」「戦術アドバイス」「死体注意点」をリアルタイム表示。
   * 識別済みアイテムの「効果概要」「BUC効果」「用途アドバイス」および、未識別アイテムの「【未識別解明ガイド】価格識別・書き込みテスト・安全識別手順」を動的提示。

5. **💖 HP / MP インタラクティブゲージバー**
   * HP/MP (Pw) のリアクティブな視覚的ゲージバー表示。

6. **🎨 GKL 3層レイヤー透過描画 ＆ 上下バウンス浮遊アニメーション**
   * **Layer 1 (Bottom)**: 地形 (壁・床・祭壇・扉など)
   - **Layer 2 (Middle)**: アイテム・箱・死体 (透過重ね合わせ描画)
   - **Layer 3 (Top)**: モンスター・自キャラ (透過 + サイン波上下バウンス浮遊運動)

## 🚀 起動方法

### ローカル Web サーバー経由で起動
プロジェクトルートでローカル Web サーバー（例: Live Server や `npx serve`）を立ち上げ、ブラウザで以下にアクセスします：

```
http://localhost:5500/examples/gkl-pure-js-client/index.html
```

---

## 📁 ディレクトリ構成

* `index.html`: GKL 2カラムレイアウト、ヘッダー、マップビュー、推奨アクションパネル、所持品インベントリ
* `main.js`: `WebUICore` ＆ `GKL (SituationCache)` 統合コントローラー
* `style.css`: レスポンシブな GKL スタイルシート
