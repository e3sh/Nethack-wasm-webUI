# Nehww - NetHack Wasm WebUI 公式リファレンスクライアント (GKL Pure JS Client)

> **📖 プレイヤー向けの遊び方・画面の見方はこちら**  
> [**👉【Nehww】操作ガイド (PLAYER_GUIDE.md)**](./PLAYER_GUIDE.md)

**Nehww** (`examples/gkl-pure-js-client`) は、**Pure JS Client (`examples/pure-js-client`)** の安定したクライアント基盤（全プロンプト、メニュー、キー入力、WASM Worker 通信、セーブ・復元等）をベースに、**GKL (Game Knowledge Layer)** の知識層およびモダンな UI（Neo-Retro Dark Glass イマーシブHUD）を完全統合した公式リファレンスクライアントです。

---

## 🌟 主な特徴と機能

### 0. 🌌 全画面ダンジョンマップ ＋ イマーシブHUD (Neo-Retro Dark Glass UI)
* **全画面マップ（100vw × 100vh）**:
  * 画面全体に広がるダンジョン視界。マウスホイールによるスムーズなズーム調整に対応。
* **フロストガラス・オーバーレイHUD**:
  * フロストガラス（`backdrop-filter: blur`）によるゲームUI。
  * **💬 フローティングメッセージHUD**: 最新メッセージが視界を遮らず中央上部にスマートに表示。
  * **📜 過去ログドロワー (`MessageHistoryDrawer`)**: `Ctrl+P` またはメッセージクリックでスライド展開。ピン留め（📌）により画面左端への常時固定・自動追従スクロールが可能。
  * **🎒 右サイドパネルの一時退避・即時復帰**: `Alt+S` または `F2` キー、画面右端の `🎒 所持品` Peekタブにより、戦闘中や全画面探索時にワンタップで出し入れ可能。

### 1. 3つの描画エンジン ＆ カメラ追従
* **✨ HD-2D ビューポート (`WebGPUHD2DRenderer`)**:
  * WebGPU による 3D ジオラマ風グラフィック。斜め見下ろしの「ジオラマ視点」と、真上からの「トップビュー視点」のカメラアングル切り替えに対応。
* **🎨 2D グラフィックビューポート (`MainViewportRenderer`)**:
  * 32px 原寸スプライトによる高精細描画。主人公を中心とするスムーズなカメラ追従（Lerp 補間）。
  * 視界内モンスターや自キャラの上下浮遊運動、斬撃・被弾・回復等の Visual FX、画面振動。
* **🔤 Color ASCII Grid**:
  * NetHack 伝統の 80×24 カラーテキスト画面表示。

### 2. 🗺️ フロア全体 ミニマップ HUD (`MinimapHudRenderer`)
* 画面右上にフロア全体の縮小マップを描画（自キャラ発光、モンスター、階段・祭壇・店舗等のランドマーク）。
* `[Tab]` キーまたはクリックで画面中央へ**半透明拡大（最大化）トグル**可能。
* 自キャラ接近時の**スマートドッキング（左上退避）**と、重なり時の**半透明ゴースト化**を搭載。

### 3. 🧠 推奨アクションパネル ＆ 8方向 D-Pad (`DirectionPad`)
* 周囲のモンスター、地形、扉、足元の仕掛け、所持道具から実行可能なアクションを優先度順に自動提示。
* **8方向 D-Pad**: 方向ボタンでアクション一覧の方角絞り込み、長押しで1歩移動・待機、ダブルタップでダッシュ移動を実行。
* 各方角の実行可能件数を示す数字バッジを表示。
* 危険を伴う行動には誤操作防止の確認ダイアログを表示。

### 4. 🎒 アイコン型常時表示インベントリ (`InventoryView`)
* 所持アイテムをグリッドアイコンで常時可視化。
* 装備状態バッジ（「手」「副」「筒」「着」）、職業適性「+」バッジ、BUC（祝福/呪い/未識別）バッジ。
* **ワンタップ即時使用**: クリックで食べる、飲む、読む、装備などを実行。
* **サブメニュー**: 長押しまたは右クリックで投げる、置く、名前をつける（仮名付けアシスト）等のメニューを展開。
* ペーパードールやコンテナへのドラッグ＆ドロップに対応。

### 5. 💡 構造化ナレッジ ＆ 🛡️ 戦術アドバイス (`KnowledgeView`)
* **💡 ナレッジタブ**: マップタイルや所持品の右クリック・ホバーで、対象モンスターやアイテムの詳細スペック（危険度、ステータス、耐性、死体摂食の安全性、鑑定法等）を表示。
* **🛡️ 戦術アドバイスタブ**: プレイヤーの飢餓・健康状態、周囲の強敵への対処法、装備提案などをリアルタイム通知。

### 6. 🚨 HUD 最優先アシストシグナルバー (`AssistHud`)
* 瀕死や致命的な危険が発生した際、画面上部に警告バーが出現。
* ワンタップで危機回避行動を実行できるアクションボタンと、推奨理由（Why）の解説を搭載。

### 7. 🏛️ 床文字・考古学的復元 HUD (`EngravingHud`)
* 床の刻み文字（Elbereth 等）を踏んだ際、ステータスバー上に原型同定・完全日本語訳バナーが出現。「[E] 再刻み」ボタンで結界を修復可能。

### 8. 🗺️ ダンジョン探索トラッカー ＆ フロアメモ (`FloorTrackerModal`)
* `Ctrl+O` または `Alt+A`、あるいはステータスバーの `Dlvl` クリックで起動。
* 全階層の踏破状況、階段・店・祭壇・泉等の設備一覧を確認可能。
* 階層ごとのフロアメモ（`#annotate` 連携）の記録。
* 現在地の足元座標への絵文字ピン・カスタムマーカー設置（ダンジョンマップおよびミニマップ上にオーバーレイ描画）。

### 9. 充実した特化型 GUI モーダル群
* **👤 キャラクター詳細ダイアログ (`CharacterStatusModal`)**:
  * 能力値詳細、内在・外在耐性一覧、修得呪文のワンクリック詠唱、スキル向上（`#enhance`）。
* **🎽 装備詳細ペーパードール (`PaperdollModal`)**:
  * 全身13スロットの装備一覧。AC変化の比較や着脱ターン数の確認、呪い装備の警告。
* **📖 冒険手帳 (Adventure Log & Codex) (`CodexModal`)**:
  * セッション横断のメタプログレッション（モンスター全383種、アイテム全481品、噂話787件の真偽自動判定、神託20件、床文字アーカイブ）。検索・フィルタ・一括既読に対応。
* **📦 ビジュアルコンテナ UI (`ContainerModal`)**:
  * チェストや鞄とのアイテム・金貨の相互移動。バッグ・イン・バッグ等の危険操作を自動防止。
* **✨ 特殊安全支援ウィザード群**:
  * **願い (`WishModal`)**: おすすめプリセット、祝福・強化値・材質・油塗りのGUI設定、コマンドプレビュー。
  * **虐殺 (`GenocideModal`)**: 危険モンスターのプリセット、自己抹殺防止ロック、不殺戒律警告。
  * **変化 (`PolymorphModal`)**: 変身先候補、防具破壊の事前警告、飛行/壁抜けフィルタ。
  * **筆記 (`WriteModal`)**: 巻物・魔法書の書き込み候補、残インク消費予測、安全性表示。

### 10. ⚙️ 設定メニュー
* 右上の設定メニューから、プレイスタイルに合わせたレイアウト変更が可能（設定はブラウザに自動保存）。
  * **⚔️ クラシック (原作風)** / **🛡️ GKL モダン (標準)** プリセット。
  * 描画方式（HD-2D / 2Dグラフィック / Color ASCII Grid）および HD-2D カメラ視点（ジオラマ / トップビュー）の切替。
  * 各種HUD表示の個別 ON/OFF、キー入力のネイティブ透過設定。

## 🚀 起動方法

### ローカル Web サーバー経由で起動
プロジェクトルートでローカル Web サーバーを立ち上げ、ブラウザで以下にアクセスします：

```
http://localhost:5500/examples/gkl-pure-js-client/index.html
```
