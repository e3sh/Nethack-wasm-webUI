# NetHack Wasm WebUI - GKL Pure JS Reference Client

> **📖 プレイヤー向けの遊び方・画面の見方はこちら**  
> [**👉【GKLpureJSclient】かんたん操作ガイド (PLAYER_GUIDE.md)**](./PLAYER_GUIDE.md)

`examples/gkl-pure-js-client` は、**Pure JS Client (`examples/pure-js-client`)** の安定した完全なクライアント基盤（全プロンプト、メニュー、キー入力、WASM Worker 通信、セーブ・復元等）をベースに、**GKL (Game Knowledge Layer)** のインテリジェント機能およびモダンなリッチ UI を完全統合した公式リファレンスクライアントです。

---

## 🌟 主な特徴と GKL 拡張機能

### 1. 迫力ある 3 つの描画エンジン ＆ カメラ追従
* **✨ HD-2D ビューポート (`WebGPUHD2DRenderer`)**:
  * WebGPU による 3D ジオラマ風グラフィック。見下ろし斜め45度（ジオラマ）、真上（トップビュー）、追従（ショルダービュー）のカメラアングル切り替えに対応。
* **🎨 2D グラフィックビューポート (`MainViewportRenderer`)**:
  * 32px 原寸スプライトによる高精細描画。主人公を中心とするスムーズなカメラ追従（Lerp 補間）。
  * 視界内モンスターや自キャラの上下バウンス浮遊運動、斬撃・被弾・回復等の Visual FX、画面振動（Screen Shake）。
* **🔤 Color ASCII Grid**:
  * NetHack 伝統の 80×24 カラーテキスト画面表示。

### 2. 🗺️ フロア全体 ミニマップ HUD (`MinimapHudRenderer`)
* 画面右上にフロア全体の縮小マップを常時描画（自キャラ発光パルス、モンスター赤ドット、階段・祭壇・店舗等のランドマークピン留め）。
* `[Tab]` キーまたはクリックで画面中央へ**半透明拡大（最大化）トグル**可能。
* 自キャラが右上に近づくと自動で左上へ退避する**スマートドッキング（Smart Docking）**と、重なり時の**半透明ゴースト化**を搭載。

### 3. 🧠 GKL 推奨アクションパネル ＆ 8方向 D-Pad (`DirectionPad`)
* 周囲のモンスター、地形、扉、足元の仕掛け、所持道具から「今最も有益なアクション」を優先度順にリアルタイム自動提示。
* **8方向 D-Pad**: 方向ボタンでアクション一覧の「方角絞り込みフィルター」、長押しで「1歩移動・待機」、素早いダブルタップで「ダッシュ移動（走り）」を実行。
* 各方角の実行可能件数を示す**赤数字バッジ**を表示。
* 命に関わる危険な行動（赤ボタン）には誤操作防止の確認アラートを搭載。

### 4. 🎒 アイコン型常時表示インベントリ (`InventoryView`)
* 所持アイテムをグリッドアイコンで常時可視化。
* 装備状態バッジ（「手」「副」「筒」「着」）、職業に応じた得意武器「+」バッジ、BUC（祝福/呪い/未識別）バッジ、おすすめ・危険ハイライト枠。
* **ワンタップ即時使用**: クリックで食べる、飲む、読む、装備などを即座に実行（換装プランナーによる自動着脱計算と安全確認付き）。
* **詳細メニュー**: 400ms 長押し または 右クリック で投げる、置く、名付ける等の詳細アクションメニューを展開。
* ペーパードールやコンテナへのドラッグ＆ドロップに対応。

### 5. 💡 構造化ナレッジ ＆ 🛡️ 戦術アドバイス (`KnowledgeView`)
* **💡 ナレッジタブ**: マップタイルや所持品のホバー/クリックで、対象モンスターやアイテムの完全な図鑑カード（危険度バッジ、レベル・AC・推定HP、死体の毒・石化警告、実戦戦術アドバイス、アイテム適応スペック等）を表示。
* **🛡️ アドバイスタブ**: プレイヤーの飢餓・健康状態、周囲の強敵への対処法、装備提案などをリアルタイム通知。緊急事態（CRITICAL）には赤色警告と推奨キー操作を案内。

### 6. 🚨 HUD 最優先アシストシグナルバー (`AssistHud`)
* 瀕死や致命的な危険が発生した際、画面上部に最優先警告バーが出現。
* ワンタップで危機回避行動を実行できるアクションボタンと、推奨理由（Why）の解説ツールチップを搭載。

### 7. 🏛️ 床文字・考古学的復元 HUD (`EngravingHud`)
* 床の刻み文字（Elbereth 等）を踏んだ際、ステータスバー下に原型同定・完全日本語訳バナーが出現。「[E] 再刻み」ボタンで結界をワンタップ修復可能。

### 8. 充実した特化型 GUI モーダル群
* **🎽 装備詳細ペーパードール (`PaperdollModal`)**:
  * 全身の装備スロット（頭・鎧・盾・小手・靴・マント・指輪・魔除け等）をビジュアル化。AC 比較やドラッグ＆ドロップ換装をサポート。
* **📜 冒険手帳 (Rumor & Lore Codex) (`CodexModal`)**:
  * ゲーム中に収集した噂話（真実／偽り）、神託、床文字・落書きのアーカイブ。総収集率や英和完全対訳の検索・閲覧が可能。
* **📦 ビジュアルコンテナ UI (`ContainerModal`)**:
  * チェストや袋を開けた際、2ペインのビジュアルインベントリ GUI で直感的にアイテム移動。
* **✨ 願いビルダー (`WishModal`)**:
  * 祝福・強化値・耐性（防錆等）を GUI で組み立て可能。日本語・英語・略称（SDSM 等）インクリメンタル検索と誤爆防止セーフティガード付き。
* **💀 虐殺アシスタント (`GenocideModal`)**:
  * おすすめ危険モンスター／クラスのプリセット選択、検索、自己虐殺（Self-Genocide）防止プロテクト。
* **🦎 変化制御アシスタント (`PolymorphModal`)**:
  * おすすめ定番モンスター図鑑、保有耐性・能力値・サイズプレビュー、変身時の防具破壊警告。
* **🖋️ 魔法のマーカー書き込みアシスタント (`WriteModal`)**:
  * 未知の巻物・魔法書の書き込み候補カタログとインクリメンタル検索。

### 9. ⚙️ 外観・レイアウトカスタマイズ
* 右上の設定メニューから、プレイスタイルに合わせたレイアウト変更が可能（設定はブラウザに自動保存）。
  * **⚔️ クラシック (原作風)**: 描画ビューを ASCII 表示へ切り替え、1カラム全画面・サイドパネル非表示・ミニマップHUD OFF・常時2行ステータス。
  * **🛡️ GKL モダン (標準)**: 描画ビューを ✨ HD-2D（3Dジオラマ風）へ切り替え、2カラム全枠表示・ミニマップHUD ON・ゲージバー・耐性/魔法/スキル行表示。
  * サイドパネル（所持品・推奨アクション・アドバイス）の個別 ON/OFF。
  * ビュー切替（HD-2D / 2Dグラフィック / Color ASCII Grid）および HD-2D カメラアングル切替。

## 🚀 起動方法

### ローカル Web サーバー経由で起動
プロジェクトルートでローカル Web サーバー（例: VS Code Live Server や `npx serve`）を立ち上げ、ブラウザで以下にアクセスします：

```
http://localhost:5500/examples/gkl-pure-js-client/index.html
```
